以下過半数判定の解説

  例1: [1, 1, 1, 3, 3, 3, 3]（7ノード）

  ソート方式：
  sorted = [1, 1, 1, 3, 3, 3, 3]
  中央のインデックス = 7 // 2 = 3
  sorted[3] = 3  ← 結果

  Counter方式：
  Counter({3: 4, 1: 3})
  過半数 = 7 // 2 + 1 = 4
  3が4回 → 過半数！ ← 結果

  ---
  なぜ同じ？

  ソートで真ん中の値を取るということは：
  - その値以下を持つノードが過半数
  - その値以上を持つノードが過半数

  つまり、「その値がちょうど過半数の境界」という意味です！

  視覚化：
  [1, 1, 1, | 3, | 3, 3, 3]
   ↑ 3個   ↑中央  ↑ 3個

  3を持っているのは 4ノード（右側の3が4個）= 過半数！

  ---
  例2: [0, 3, 7]（3ノード）
  sorted = [0, 3, 7]
  中央 = 3 // 2 = 1
  sorted[1] = 3

  これは「3以上を持っているのが2ノード（過半数）」という意味：
  - 0のみ: 1ノード
  - 3以上: 2ノード ← 過半数
  - 7: 1ノード

  数学的な理由：
  ソートした配列の中央値 = 過半数が持っている最大値

  だからソートでもCounterでも同じ結果になります！

● 良い指摘です！でも実はソートで正しいんです！

  例：[1, 1, 2, 2, 2, 3, 3]（7ノード）

  sorted = [1, 1, 2, 2, 2, 3, 3]
  中央のインデックス = 7 // 2 = 3
  sorted[3] = 2  ← 結果

  なぜこれが正しい？

  Raftのmatch_indexは「そのノードがインデックスXまで複製した」という意味です。つまり：

  - match_index = 1 → インデックス0, 1を持っている
  - match_index = 2 → インデックス0, 1, 2を持っている
  - match_index = 3 → インデックス0, 1, 2, 3を持っている

  だから [1, 1, 2, 2, 2, 3, 3] の場合：
  - インデックス2以上を持っているノード = 5個（2,2,2,3,3）→ 過半数！
  - インデックス3以上を持っているノード = 2個（3,3）→ 過半数未満

  よって、commit_index = 2 が正しい！
